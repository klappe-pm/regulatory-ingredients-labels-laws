# regulatory-labeling-readme

Private-visibility save target for outputs of the regulatory-labeling prompt library (`public/prompts/`). Every prompt note in that library whose `visibility` is `private` directs its Microsoft 365 Copilot output here, at `{private_folder}`. The one public-visibility exception (the `copilot-configuration` category) saves to `public/regulatory-labeling/` instead.

Files land here as the specialist runs prompts and saves results; this folder has no fixed sub-structure. Organize by SKU, by workstream, or by date as it fills, whichever the specialist finds fastest to search.
