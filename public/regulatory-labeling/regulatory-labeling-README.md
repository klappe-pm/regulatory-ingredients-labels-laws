# regulatory-labeling-readme

Public-visibility save target for outputs of the `copilot-configuration` category in the regulatory-labeling prompt library (`public/prompts/copilot-configuration/`), the one category in that library marked `visibility: public`. Routing decisions produced by `personalization-install-router` land here; they are Copilot-configuration guidance, not label content, and carry no product-specific regulatory information. Every other category's outputs save to `projects/regulatory-labeling/` instead.
