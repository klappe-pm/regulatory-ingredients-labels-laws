# environment-README

These documents describe the local development environment that informed the
scaffolding project.

## Canonical Setup Record

- `environment-keychain-env-setup.md` records the Keychain-backed environment variable setup
  and is the canonical setup history.

## Compatibility Guides

- `environment-global-credentials-guide.md` explains project-wide credential access
  patterns.
- `environment-ide-credentials-guide.md` explains terminal and IDE compatibility.

## Machine Profile

- `environment-macos-machine-specs.md` records the local Mac hardware and OS profile.

## Boundary

Do not copy these documents into new projects. Generated projects should receive
only safe references such as `.env.example`, credential setup placeholders, and
links to local setup docs when appropriate.
