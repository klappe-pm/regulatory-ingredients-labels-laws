## Key Decisions

- The standardized record is the basis for both the briefing and the exportable
  database, so the patterns the team sees and the data we can mine are the same.
- The newsletter is a single file regenerated each run that links every record
  to its source; the export emits one normalized row per obligation.
- The one-pager is addressed to Diane Tran (dtran@talkingrain.com) and asks for
  feedback on content, the right depth per audience, and the report cadence
  (frequency remains open by request).
- The data-model and visualization files are explicitly forward sketches (a
  v5-or-later direction) but ride on the working `export`.
