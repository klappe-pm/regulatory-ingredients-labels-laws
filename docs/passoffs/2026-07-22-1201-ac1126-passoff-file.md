## Key decisions

- The existing research library remains the evidence layer and is extended rather than replaced.
- The product is an authenticated, web-hosted research and review workspace with browser UI and server-side agent tools.
- MUI Core and MUI X Data Grid are the proposed component foundation, with a regulatory fieldbook visual language and persistent evidence context.
- Regulatory detections remain provisional until evidence and review gates are satisfied; the system does not automatically issue legal approval.
- AWS versus GCP, identity provider, domain and DNS, retention policy, source contracts, and numeric operating-cost assumptions remain explicit decision gates.
- The plan is intentionally marked `REVISE`, not agent-ready, until those gates and source contracts are resolved.

## Risks and open questions

- Hosting provider, identity provider, domain, DNS, data residency, retention, and deletion policy remain undecided.
- Source-specific acquisition contracts, licensing constraints, authoritative endpoint verification, and API ownership need evidence before implementation.
- Cost figures require measured traffic, storage, retrieval, model, staffing, and compliance assumptions before a defensible financial model can be approved.
- Label and formulation review requires clear jurisdiction routing, confidence thresholds, reviewer authority, and strict separation from legal advice.
- The primary checkout contains a large unrelated dirty and diverged change set plus an older stash. Those items are not owned by this workstream and must not be swept into this commit or discarded during cleanup.

## Lessons learned

- Lesson: define the user workflows, evidence boundaries, and decision rights before selecting source integrations or cloud components.
- Why it matters: architecture can look complete while still failing to support defensible timelines, label review, saved research, or human accountability.
- How to apply next time: require every product capability to map to a named user goal, authoritative evidence, provenance fields, review state, and acceptance test.

- Enforced by: the plan evaluation, decision register, evidence contract, and adversarial acceptance gates.
