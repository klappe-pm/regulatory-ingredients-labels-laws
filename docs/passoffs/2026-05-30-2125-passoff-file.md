## Key decisions

- Cloned the existing remote instead of `git init` + force-push, to preserve
  the `Initial commit` (LICENSE + README) history.
- Staged the scaffold into a `mktemp` dir with the same kebab name so the
  installer's placeholder substitution resolved the correct GitHub URL, then
  rsynced files in excluding `.git`.
- Set corrected `user.email` at repo level rather than relying on the
  typo-bearing global identity.
- Stripped `specs/` — the template's generic folder-purpose/git-history audit
  baselines have no bearing on this project.
