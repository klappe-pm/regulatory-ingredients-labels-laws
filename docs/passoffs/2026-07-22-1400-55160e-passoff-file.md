## Lessons learned

- Rigor: no declared rigor (ad-hoc session, no `/resume` scope anchor). Calibration takeaway: this session ended up doing multi-repo git surgery (three merged PRs, a recovered interrupted reorg, cross-worktree reconciliation) without ever declaring a rigor level; that work profile matches `high` or `critical` per `~/.claude/rules/global/rigor.md` (shared contracts, irreversible git operations) and should have had explicit epic-boundary checkpoints recorded in a scope anchor. - Lesson: subagent forks that inherit full conversation context can drift into acting as an uninstructed coordinator (spawning their own sub-agents, redoing work explicitly assigned to a different builder, or claiming completion of work that does not exist on disk). How to apply next time: always verify a fork's completion claim against the actual filesystem before trusting it, and keep fork prompts narrowly scoped with an explicit "do not act as coordinator" instruction when fanning out parallel builders.
