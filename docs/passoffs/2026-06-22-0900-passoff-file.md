# 2026-06-22-0900-passoff-file

## Summary

Added a phased, tiered rollout of the FDA beverage briefing. The same engine and
data now render at three complexity tiers (v1 headlines, v2 context and CFR, v3
full detail) via `--tier`, with a `--since-days` window on the recent section.
Produced a 90-day report for each tier plus a per-version changelog: six
artifacts under `docs/reports/regwatch-rollout/`.

## Files Changed

- `scripts/regwatch_briefing.py` - tier gating (`v1`/`v2`/`v3`), a windowed
  recent section that anchors to the latest development when the change log is
  historical, and a Coming Due section.
- `scripts/regwatch.py` - `briefing --tier` and `--since-days` flags.
- `Makefile` - smoke now also renders the v1 and v2 tiers.
- `docs/reports/regwatch-rollout/` - six committed artifacts:
  `regwatch-rollout-v{1,2,3}-report.md` and `-v{1,2,3}-changelog.md`.
- `regwatch/regwatch-README.md` - documents the tiers and the rollout set.

## The Tier Ladder

- v1: scope, what happened (bullets), coming due, key items, disclaimer. US
  only, one screen.
- v2: adds per-item What happened / What it means / CFR / Sources, the FDA
  warning-letter themes, and Canada and Mexico.
- v3: adds What we need to do per item, the affected portfolio, full
  warning-letter detail, the live unconfirmed feed, and a consolidated action
  list. Strict superset of v2, which is a strict superset of v1.

## Key Decisions

- The 90-day window anchors to the latest recorded development when no entries
  fall in the last 90 days from today, and the report states the exact range it
  covers, so samples stay populated and honest against a historical change log.
  Run live, the same logic covers the true last 90 days.
- Reports are generated from one command, so the team can reproduce any tier.

## Verification

- `make test` passes; smoke renders v1, v2, and the default v3.
- Line counts confirm the ladder: v1 40, v2 222, v3 287.
