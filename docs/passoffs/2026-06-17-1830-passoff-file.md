# 2026-06-17-1830-passoff-file

## Summary

Added the analysis-and-delivery layer on top of the regwatch engine: daily and
weekly update loops, content synthesis, a CPG impact suite mapped onto a Talking
Rain portfolio model, a beverage analytical lens, and multi-format outputs
(Word document, email newsletter, web posting).

## Files Changed

- `regwatch/regwatch-talking-rain.json` - Talking Rain portfolio model
  (products, ingredient functions, claims, sales channels).
- `regwatch/regwatch-schema.json` - added `portfolio_fields` and a `channels`
  reference; portfolio validated by `make regwatch-validate`.
- `scripts/regwatch_impact.py` - CPG impact assessment (three match gates,
  severity scoring) and the beverage-category lens.
- `scripts/regwatch_synthesis.py` - daily and weekly document-model synthesis.
- `scripts/regwatch_render.py` - renderers: `.docx` (stdlib WordprocessingML
  zip), email newsletter (HTML plus text), web posting (markdown front matter).
- `scripts/regwatch.py` - new commands: `portfolio`, `impact`, `beverage`,
  `brief`; portfolio validation wired into `validate`.
- `.github/workflows/regwatch.yml` - weekly loop now also renders the brief.
- `.github/workflows/regwatch-daily.yml` - new daily loop.
- `Makefile` - `regwatch-brief` target.
- `docs/reports/regwatch-samples/` - committed sample outputs in every format.
- `regwatch/regwatch-README.md`, `docs/plans/deliverable-3-regulatory-monitoring-design.md`,
  `docs/plans/delivery-plan.md` - documentation updates.

## Key Decisions

- Impact matching requires all three gates: jurisdiction or channel reach,
  school/SNAP scope, and an attribute match on function, named ingredient, or
  claim. Direct named-ingredient matches score above function-only.
- Beverage lens names a product affected only when it actually carries the
  theme's ingredient function, so the synthesis does not overstate exposure.
- `.docx` is generated directly as a zip of WordprocessingML parts to honor the
  standard-library-only rule; the newsletter ships HTML plus a plain-text
  alternative; the web post is markdown with draft front matter.
- The Talking Rain portfolio is an internal model flagged `internal-model`;
  attributes must be confirmed against current specs.
