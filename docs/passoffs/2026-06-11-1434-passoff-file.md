## Lessons learned

- The `Makefile` `AUDIT_DOCS` is an allowlist (`docs/plans/` + the reference
  READMEs only). `docs/reports/` and the source folders are not audited, which
  is what lets a Marp deck live in-repo without failing `make audit-strict`.
  Plans in `docs/plans/` are strictly audited — H1 must equal the filename
  stem, H2-H6 must be Title Case (acronyms and `(parentheticals)` pass), and
  only `[[wikilinks]]` are resolution-checked (inline `[text](path)` links are
  not).
- `poppler` is not installed on this machine, so the Read tool cannot render
  PDF pages; subagents fell back to text extraction (pdfminer/pypdf/pdfplumber)
  for the source decks.
- No `docs/lessons/` file created this session.
