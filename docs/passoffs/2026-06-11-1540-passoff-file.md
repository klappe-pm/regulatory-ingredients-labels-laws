## Lessons learned

- marp-cli treats `--pdf` and `--pptx` as mutually exclusive — run two
  invocations, not one combined command.
- `.claude/` is already globally ignored via `~/.claude/.gitignore` (`**/.claude/`);
  project-local `.claude/` needs no per-project ignore entry.
- To isolate staged work into a linked worktree without committing in the
  primary: `git stash --include-untracked`, `git checkout` the default branch,
  `git worktree add <path> <branch>`, then `git stash pop` in the new worktree.
- No `docs/lessons/` file was created this session.
