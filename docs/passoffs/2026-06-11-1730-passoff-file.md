## Lessons learned

- A passoff that merges cleanly by `git merge-tree` can still look destructive
  in a two-endpoint `git diff` when the target branch added files the source
  branch never saw (here, the `1540` passoff). Trust the three-way merge check,
  not the diff, before landing.
- Concurrent sessions in separate worktrees are isolated for safety (committed
  work survives a sibling's `git clean`/reset of another checkout), but the
  cross-worktree *landing* of a branch is guarded by process + human
  confirmation, not a hard lock. Re-check `git worktree list` / `reflog` before
  acting. No `docs/lessons/` file created.
